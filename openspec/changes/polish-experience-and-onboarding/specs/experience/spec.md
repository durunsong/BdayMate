# 验收标准

- 顶部导航加载条在用户触发实际站内页面跳转时出现，完成/取消后消失；不阻碍点击和读屏，不为外链/同页锚点/修饰键开启。
- 全站首页、认证与业务页均可选择系统/日光/夜色，刷新及新导航保留偏好；表单、弹窗、表格、日历、图表、消息与按钮无漏色和低对比文字。
- 注册后显示发往邮箱及查收、点击验证链接的步骤；重发有等待反馈、失败可恢复；查询参数不能伪造成功。
- 五类邮件（验证、重置、测试、提醒、祝福）有统一完整视觉；自定义祝福保持换行、转义与隐私，默认文案自然且可编辑。
- 根路径展示动效产品首页，CTA真实可用；手机和减少动态效果仍可读可用，动画不承诺尚未实现的功能。
- 共享按钮加载前后图标/文字对齐，双击防护正确，键盘可用；已登录访问登录/注册/忘记密码页会转入工作台。
- 最终回归和生产构建通过，所有任务改动提交并正常推送，正式部署可访问。
