# 公开首页设计

## 目标与范围

首页帮助首次访问者理解生日搭子的用途，并进入注册；已登录用户仍可浏览首页，主要入口返回工作台。保留现有 Logo、暖靛蓝品牌和全局主题，不改写认证、生日计算或提醒业务。

验收：根路径不重定向；注册与登录链接可用；已登录 CTA 指向工作台；公历/农历切换更新解释与示意；装饰动效可暂停；减少动态与手机宽度下内容可读且无横向溢出。

## 视觉方向

模式为 Persuade。以“把在乎，放进日历”为主标题，日历纸张与生日轨道承担首屏主视觉；留白和大标题沿用现有品牌语言，纸张、信封、礼物与手绘日期圈增加温度。Logo 直接复用共享 Brand，不重新绘制。

页面依次为主张与轨道场景、功能速览、可操作历法解释、礼物与祝福叙事、注册收尾。所有装饰人物与日期明确标为产品示意，不显示虚构用户评价、使用人数或真实账户数据。

公历/农历演示只解释现有计算方式，不在客户端另写日期引擎，不以静态数据冒充真实的年份换算。

## 动态与可访问性

- 首屏日历轻浮动、轨道运动、日期笔迹形成一个完整动效场景；有全页暂停按钮。
- IntersectionObserver 只触发一次滚动入场，默认内容可见；没有脚本或观察器时仍可阅读。
- 公历/农历按钮使用原生 button 和 aria-pressed，说明区域使用 aria-live。
- 减少动态偏好关闭动画和过渡；跳转链接、锚点、键盘焦点沿用原生交互。
- SVG 礼物与信封随滚动展开；装饰图形从无障碍树隐藏，文字解释独立存在。
- 页面样式限定于 landing 命名空间，颜色来自共享主题变量，附加暖色在 data-theme=dark 下调整。

## 实现与验证入口

- 路由：`src/app/page.tsx`。
- 页面和局部样式：`src/features/landing.tsx`、`src/features/landing.css`。
- SSR 行为：`pnpm exec vitest run tests/unit/landing.test.ts`。
- 浏览器行为：`tests/e2e/landing.spec.ts`，由统一 Playwright 服务执行，避免重复占用端口。
- 不新增依赖，不访问外部图片服务。
