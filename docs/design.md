# BdayMate 界面方向

采用 Operate 模式：让用户在首屏看清今天、近期生日与下一步行动。遵循用户指定的浅色 SaaS、靛蓝主色与橙粉生日提示；使用系统中文字体，避免构建时下载字体。

- 桌面：固定的窄导航、清晰页标题、宽松的主内容列；移动端使用可关闭的无障碍抽屉。
- 主色 #6366F1，深色可读文字 #1E293B，次要文字 #64748B，背景 #F8FAFC，白色内容面。生日强调使用浅杏色与珊瑚色。
- 主要信息优先：五项真实统计、今天生日和近期时间线；空数据给出添加入口，不生成示例联系人。
- 一致组件：44px 交互区域、可见键盘焦点、Radix 对话框、明确成功/失败反馈，提交期间禁止重复操作。
- 生日由 BirthdayService 统一计算；年份未知不显示年龄；历法规则、时区及跳过策略在表单里可见。
- 验收：所有业务路由可达；按钮绑定真实行为；表单有客户端/服务端校验；390px 不横向溢出；键盘能完成表单和关闭弹窗。

设计选择继承产品任务书：温暖的个人日程簿。impeccable 概念种子已执行；明确的产品配色与布局优先。视觉最终验收由主代理在集成后的桌面/移动浏览器执行。
