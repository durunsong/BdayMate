# BdayMate · 生日搭子

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

User-mandated Next.js App Router, React, TypeScript strict, Tailwind, shadcn/Radix, Better Auth, Prisma + Neon PostgreSQL, SMTP/React Email.

## Users

Individuals who want to remember birthdays of family, friends and professional contacts.

## Product Purpose

Record solar/lunar birthdays, plan gifts and send reliable reminders to the account owner, even when the browser is closed. Never Miss a Special Day.

## Capabilities and Constraints

Full scope is docs/requirements.md. Each user's data remains private. No fabricated dashboard records. Desktop and mobile web; Chinese-first copy. Public deployment target is not specified. SMTP credentials deferred by user until development is complete.

## Brand Commitments

User requests warm, lightweight SaaS dashboard, pale background, white cards, indigo primary, orange/pink birthday accents and Lucide icons.

## Accessibility & Inclusion

Keyboard navigation, labelled forms, readable contrast, reduced motion, responsive layouts, accessible confirmation dialogs.
